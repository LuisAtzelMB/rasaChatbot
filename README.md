# rasaChatbot
Hola, que tal ¿deseas empezar con este proyecto o modificarlo?.
No olvides descargarlo en tu IDE y crear un entorno de desarrollo, es la carpeta .venv, dentro de la carpeta de tu aplicación descarga los archivos de mi repositorio. 

¿Por qué descargarlo?

Este repositorio cuenta con las configuraciones necesarias para que el chatbot de raza pueda leer correctamente nuestro idioma en español.  Si deseas cambiar el idioma o alguna configuracion por favor entra a config.yml, cambia el language: ala clave de lenguaje de tu idioma, en nuestro caso español es es, de alli cambia la forma que se descompone el lenguaje natural en la sección pipeline:, Por favor si tienes dudas no dudes en comentarme,
