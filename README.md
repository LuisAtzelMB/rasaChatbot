# rasaChatbot
Hola, que tal ¿deseas empezar con este proyecto o modificarlo?.
No olvides descargarlo en tu IDE y crear un entorno de desarrollo, es la carpeta .venv. Junto con este archivo, dentro de la carpeta de tu aplicación descarga los archivos de mi repositorio. Ademas revisa que tu versión de python sea correcta, la compatible para este proyecto es la 3.9, usa el comando pip install rasa y carga los archivos del repositorio.

¿Por qué descargarlo?

Este repositorio cuenta con las configuraciones necesarias para que el chatbot de raza pueda leer correctamente nuestro idioma, el español.  Si deseas cambiar el idioma o alguna configuracion por favor entra a config.yml, cambia el language con la clave de lenguaje de tu idioma, en nuestro caso el español es "es", de alli cambia la forma que se descompone el lenguaje natural en la sección pipeline.

Por favor si tienes dudas no dudes en comentarme, mucha suerte
